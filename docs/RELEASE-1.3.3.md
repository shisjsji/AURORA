# AURORA 1.3.3

这一版上线社区：匿名分享曲线、喜欢与短评论；同时把诊断页收为二级入口，Dock 保持四格。**本版不含引擎改动，装完无需重启。**

## 一、社区页（Dock 第三格）

- 匿名分享你调的曲线：发布时自动带上机型（`17 Pro`、`17 Pro Max` 这样的友好名，来自机身代号映射，未知机型回退型号码而不是编造名字）。每张卡片在内容下方右侧显示机型——同设备的人一眼知道参考价值。
- 喜欢与短评论（≤140 字，平铺不嵌套）。喜欢的曲线收进 **设置 → 我的喜欢**。
- 曲线卡片沿用 DESIGN.md 的签名：六竖条 `EqGlyph` 缩略 + 曲线详情页的完整曲线图；计数是图标+数字，头像用内置声学主题头像组（无上传，零审核）。
- 曲线详情页可直接「保存到我的预设」，保存后出现在均衡页的「我的预设」里。

## 二、匿名身份与找回码

不用注册。第一次**发布 / 评论 / 喜欢**时服务端静默建账户，并回一个 12 位找回码（只显示一次，带复制）：

- 平时零登录感；卸载重装后在 设置 → 社区身份 → 找回已有身份 输入找回码，**内容、喜欢、昵称头像全部认领回来**。
- 昵称与头像随时可改，存在服务端账户上，认领时一起回来。
- 丢弃找回码 = 回到匿名态，不会更糟；将来要真登录，账户表加一列密码即可，不用迁移。

## 三、诊断降为二级入口

诊断的使用场景是「出问题时」，因此退出 Dock：

- **点顶部状态胶囊**直达（出问题的那一刻，入口就在眼前）；
- 设置 → 设备 → **诊断与链路**；
- 新手引导里的「查看适配详情」。

Audit 结论采纳：诊断是全五页里唯一按定义低频的页面，降级后架构零成本（全屏 Panel 模式现成），Dock 保持 84dp/格 的舒适宽度与水滴手感。

## 四、审计加固（1.3.3 同期）

- 恢复码改用 CSPRNG（`crypto.randomBytes`），此前 `Math.random` 可预测；
- 找回身份事务化 + 先释放旧设备绑定，修掉「新设备先点过赞再找回必 500」；
- 点赞建户也返回找回码，身份不再可能「无声诞生」；
- 喜欢计数下限保护、feed 的 liked 状态整页单查询；
- 喜欢按钮命中区 14dp → 36dp；
- 两个服务端代码入库 `server/`，带部署约定与回归测试脚本 `server/community/test.sh`。
