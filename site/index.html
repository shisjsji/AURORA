在系统均衡器上叠一条曲线

AURORA 用 LSPosed 注入 system_server，给每一个正在播放的会话挂一条六段曲线。 不改 /odm 里的 Dolby 配置，不重启 audioserver，不替换系统文件——关掉就回到原厂。

为什么是六段

手机扬声器只在大约 300 Hz 到 6 kHz 之间能有效还原。往 47 Hz 或 12 kHz 堆增益，曲线好看，耳朵听不出来。

所以这里只做六个点：80 / 200 / 500 / 1500 / 4000 / 10000 Hz。每一段都落在你听得见的地方，单段范围 ±12 dB，抬升有 6 dB 上限，剩下的余量留给不削顶。

挂在会话上，不是挂在设备上

系统一开空间音频，音乐就被换到独立的输出线程，全局混音上做的任何改动都会被绕过。这也是很多均衡器「装了没反应」的原因。

AURORA 按播放会话挂载，普通链路和空间音频链路都生效。没有会话在播放的时候，它什么都不做。

九套曲线

每套至少有一个频段相对平直偏 5 dB 以上，两两之间至少有一处差 4 dB。切换应该听得出来，听不出来就是没做好。

装上去要五步

  1. 确认设备已经用 KernelSU 或 Magisk 拿到 Root，并且装了 LSPosed。
  2. 安装 APK，先打开一次，让系统注册这个应用。
  3. 在 LSPosed 里启用 AURORA，作用域勾「系统」。
  4. 重启设备，让模块进入 system_server。
  5. 打开 App，开启「叠加调音」，播放任意音频就能听出区别。

适用与限制

机型
小米 17 系列（pandora / 25098PN5AC），澎湃 OS 4.0，Android 17
其它机型
没有验证过。诊断页会给出链路自检结果，可以用它判断能不能用。
不改什么
/odm 里的 Dolby 配置、persist.vendor.audio.* 属性、audioserver 进程、任何系统文件
会话切换
换歌时有两秒左右空窗，新会话被捡到之后才挂上曲线
